# 시스템 개요

## 개요

PiView는 `frontend`, `backend`, `ai`, `nginx`를 하나의 저장소에서 관리하는 모노레포 구조입니다. 사용자 요청은 프론트엔드에서 시작되고, 도메인 규칙과 데이터 저장은 백엔드가 담당하며, 피부 분석과 OCR, 검색 보조는 AI 서비스가 처리합니다.

> [!NOTE]
> 아래 흐름은 현재 저장소 기준의 대표 구조를 설명한 것입니다.
> 실제 외부 공개 경로와 노출 방식은 `nginx/nginx.conf`, 환경별 설정 파일, 배포 환경에 따라 달라질 수 있습니다.

## 시스템 구성

| 영역 | 위치 | 책임 |
| --- | --- | --- |
| Frontend | `frontend/` | 사용자 화면, 온보딩, 검색, 추천, 마이페이지 |
| Backend | `backend/` | 인증, 사용자/제품/루틴 API, 추천 오케스트레이션 |
| AI | `ai/` | 피부 분석, OCR, 검색/챗봇 보조 로직 |
| Infra | `docker-compose.yml`, `nginx/` | 컨테이너 운영, 라우팅, 배포 환경 구성 |

## 요청 흐름

### 피부 진단 흐름

1. 사용자가 프론트엔드 온보딩 화면에서 이미지를 업로드합니다.
2. 프론트엔드 요청은 배포 경로에 따라 백엔드를 거치거나, 인프라 라우팅을 통해 AI 서비스와 연결됩니다.
3. AI 서비스가 얼굴 이미지 분석 결과를 생성합니다.
4. 설문 응답과 분석 결과가 결합되어 피부 타입과 추천 기준이 만들어집니다.

### 제품 탐색 흐름

1. 사용자가 검색 또는 추천 화면에서 조건을 입력합니다.
2. 백엔드가 제품 카탈로그, 사용자 정보, 회피 성분 데이터를 조회합니다.
3. 필요한 경우 AI 서비스가 검색 질의를 보정하거나 랭킹 보조 결과를 생성합니다.
4. 최종 결과가 프론트엔드에 전달됩니다.

### OCR 등록 흐름

1. 사용자가 제품 사진을 업로드합니다.
2. AI 서비스가 텍스트를 추출합니다.
3. 백엔드가 내부 제품 데이터와 연결해 사용자 보유 제품으로 저장합니다.
