# 4. 시연 시나리오

## 1. 시연 개요

PiView 시연은 피부 타입 분석에서 출발해 보유 제품 등록, 성분 충돌 확인, 추천, 루틴 저장, 검색, 비교, 챗봇까지 이어지는 전체 사용자 흐름을 보여주는 데 초점을 둔다.
핵심은 사용자의 피부 정보와 현재 루틴 맥락이 이후 추천과 검색, 챗봇까지 계속 이어진다는 점이다.

상세 대본은 [시연 시나리오(참고).md](시연%20시나리오(참고).md)에 정리했다.

## 3. 시연 흐름 요약

1. 피부 타입 분석 시작
2. 카메라 촬영 및 설문 입력
3. 피부 분석 결과 확인
4. 내 루틴 진입 및 보유 제품 등록
5. 의도적으로 성분 충돌 상황 생성
6. PiView 추천으로 대체 제품 추천 확인
7. 추천 제품 추가 후 루틴 완성
8. 루틴 분석, 성분 충돌, 팁 확인 후 저장
9. 내 루틴 리스트와 홈 메인 루틴 확인
10. 마이페이지에서 보유 제품 및 제외 제품 관리
11. 검색, 상세, 비교, EWG 확인
12. 추천 페이지와 가미나이 챗봇 시연

## 4. 시연 포인트

- 이미지와 설문이 함께 최종 피부 결과를 만든다.
- 일부러 성분 충돌을 만든 뒤 추천 로직이 이를 어떻게 보정하는지 보여준다.
- 루틴 점수, 성분 충돌, 팁처럼 AI 분석 결과가 저장 직전 의사결정을 돕는다.
- 검색, 비교, 추천, 챗봇 모두 사용자 피부 정보와 기존 문맥을 이어받는다.
