# Generated Dictionaries

- `brands.generated.json`: DB 기준 브랜드 사전
- `categories.generated.json`: DB 기준 카테고리 사전
- `product_types.generated.json`: 카테고리/상품명 기준 타입 사전
- `ingredients.generated.json`: 전성분 기준 성분 사전
- `line_terms.generated.json`: 상품명 기준 라인명 후보 사전
- `attributes.generated.json`: 상품명/설명/고민 기준 속성어 후보 사전
